# Jatin Mallarapu

I build applied AI projects, with a focus on transformer acceleration, model evaluation, serving, and developer workflows.

[MR Sentinel](https://github.com/jatinmallarapu/mr-sentinel) is my multi-agent merge request reviewer with self-hosted inference and a reproducible CI evaluation gate. [Banking77Distillation](https://github.com/jatinmallarapu/Banking77Distillation) compares prompting, fine-tuning and distillation on 3,080 test queries, with a [released Qwen student on Hugging Face](https://huggingface.co/JatinMallarapu/qwen2.5-0.5b-banking77-distill), a LoRA adapter and reproducible evaluation evidence.

[Attention Acceleration Bench](https://github.com/jatinmallarapu/attention-accel-bench) implements Triton attention and RMSNorm kernels, grouped-query attention and KV-cache experiments, with GPU correctness tests, reproducible T4 benchmarks and profiler evidence.
